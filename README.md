# Levina's 3D ASCII Birthday Bouquet & Multiverse Letter ✨

A mobile-friendly, cinematic 3D ASCII flower bouquet website built as a special birthday gift for **Levina**.

## Features
- **Cinematic Terminal Prologue:** Live day counter from the day we met (October 21, 2024), dynamic CRT scanline & vignette atmosphere, and rhythmic typewriter audio.
- **Organic 3D ASCII Bloom Animation:** Flowers and petals open organically from buds with customizable math easing curves.
- **Interactive 3D Studio:** Full touch controls (swipe to rotate 360° in 3D perspective).
- **Customization:** Choice of flowers (Sweet Pink, Deep Red, Full Tulips, Daisy Putih, Mixed), Paper Wrap, Ribbons, Baby's Breath, Floating Hearts, and Sparkles.
- **Stylized Personal Note:** Clean, heartfelt aesthetic note with multiverse quotes.
- **Zero-Dependency Web Audio:** Generative lofi ambient sound & mechanical terminal SFX using browser Web Audio API.

## Tech Stack
- Vanilla JavaScript (ES Modules)
- HTML5 Canvas for 60 FPS 3D rendering
- Modern responsive CSS
